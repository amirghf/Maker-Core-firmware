# ui
پوشه رابط کاربری (UI) نمایشگر MKS TS35 V2.

- **`ui_icons` (بند ۸.۷):** توابع گرافیکی برداری شامل آیکون‌های دورنگ ۳۲ در ۳۲ (نازل، طرح جدید فن، بستر داغ)، دکمه‌ها، آیکون‌های کوچک ۲۴ در ۲۴ (SD, USB, Menu)، آیکون جهت موتورها (مثلث بالا/پایین)، کارت گوشه‌گرد (`mc_ui_card`)، مستطیل گوشه‌گرد (`mc_ui_fill_rrect`)، مثلث پر (`mc_ui_fill_triangle`) و نوار پیشرفت (`mc_ui_progress`). همه محاسبات بدون float و با عدد صحیح انجام می‌شوند.
- **`ui_home` (بند ۸.۶ و ۸.۷):** ماژول صفحه اصلی (Home Screen) با چیدمان مدرن. چیدمان شامل نوار بالا با دکمه منو، آیکون‌های SD/USB و نام دستگاه، سه کارت گوشه‌گرد (اکسترودر، فن با درصد راست‌چین، بستر داغ) همراه با نوار پیشرفت، چهار سلول محورها (X, Y, Z, E با وضعیت ON/OFF، LED رنگی، آیکون جهت حرکت و مختصات؛ فلش جهت فقط بعد از اولین حرکت واقعی محور رنگی می‌شود)، قاب وضعیت پرینتر (READY/BUSY/KILLED/PRINTING/PAUSED) و کادر منبع ورودی (USB/OTG/SD) کنار وضعیت پرینتر، و چهار دکمه کنترلی گوشه‌گرد (START, PAUSE, STOP, RESET با برچسب متنی). این ماژول به‌صورت غیربلوک‌کننده در ۲۳ فیلد متغیر و ۱۷ مرحله قاب ثابت، صرفاً خروجی گرافیکی را روی نمایشگر نشان می‌دهد و هیچ کنترلی روی سخت‌افزار یا ورودی لمسی ندارد.
