# ui
پوشه رابط کاربری (UI) نمایشگر MKS TS35 V2.

- **`ui_home` (بند ۸.۶):** ماژول صفحه اصلی (Home Screen). وضعیت زنده دماها (اکسترودر و بستر)، هدف‌ها، موقعیت محورهای X, Y, Z, E و وضعیت دستگاه (READY / BUSY / KILLED) را به‌صورت غیربلوک‌کننده روی نمایشگر نشان می‌دهد. این ماژول صرفاً خروجی گرافیکی است و هیچ کنترلی روی سخت‌افزار یا ورودی لمسی ندارد.
