# ui
پوشه رابط کاربری (UI) نمایشگر MKS TS35 V2.

- **`ui_icons` (بند ۸.۷):** آیکون‌های برداری ساده با ابزار gfx (بند ۸.۷).
- **`ui_home` (بند ۸.۶ و ۸.۷):** ماژول صفحه اصلی (Home Screen). چیدمان شامل نوار بالا (آیکون‌های SD/USB، نام دستگاه، منو)، سه کارت (اکسترودر، فن، بستر داغ)، چهار سلول محورها (X, Y, Z, E با وضعیت ON/OFF و LED)، قاب وضعیت پرینتر (READY/BUSY/KILLED/PRINTING/PAUSED) و دکمه‌های کنترلی (play, pause, stop, reset) را به‌صورت غیربلوک‌کننده روی نمایشگر نشان می‌دهد. این ماژول صرفاً خروجی گرافیکی است و هیچ کنترلی روی سخت‌افزار یا ورودی لمسی ندارد.
