# core - هسته فرمویر MakerCore

هسته مستقل از برد (تجزیه‌کننده G-code، صف دستور، کنترل دما، برنامه‌ریز حرکت، ورودی لمس و ذخیره‌سازی).

## 🔷 ماژول‌های لمس و ذخیره‌سازی کالیبراسیون (بند ۸.۱۷)

- **`touch_input.h` / `touch_input.cpp`:** سرویس ورودی لمس با دوره زمان‌بندی `MC_TOUCH_POLL_MS` (۱۰ میلی‌ثانیه‌ای). شامل فیلتر ضدلرزش (debounce) با `MC_TOUCH_DOWN_CONFIRM` (۲ دور) و `MC_TOUCH_UP_CONFIRM` (۳ دور)، فیلتر میانگین‌گیر عدد صحیح روی مختصات خام، تولید رویدادهای فشردن (down) و رها شدن (up) به‌صورت یک‌بار مصرف، تبدیل به مختصات پیکسل با `mc_touch_apply` و کلید ایمن قطع لمس با `mc_dbg_376_touch_enable`.
- **`touch_cal_store.h` / `touch_cal_store.cpp`:** ماشین حالت غیرمسدودکننده ذخیره و بارگذاری ضرایب کالیبراسیون لمس روی EEPROM در آدرس `MC_TOUCH_CAL_ADDR` (آدرس ۵۱۲). قالب رکورد ۳۶ بایتی شامل:
  - Magic (۴ بایت: `0x4C414354UL` برابر TCAL)
  - Version (۱ بایت: `1`)
  - Reserved (۳ بایت: 0)
  - 6 ضریب float (۲۴ بایت)
  - CRC32 (۴ بایت روی ۲۸ بایت اول)
  نوشتن روی EEPROM با رعایت مرز صفحات ۳۲ بایتی انجام شده و پس از نوشتن، عملیات verify خواندن انجام می‌شود.
  *تذکر ایمنی:* کالیبراسیون لمس مربوط به سخت‌افزار برد و نمایشگر است، نه تنظیمات چاپ؛ بنابراین دستورهای `M500` تا `M503` و بازگشت به کارخانه (`M502` و `mc_cfg_apply_defaults`) این رکورد را نمی‌خوانند، نمی‌نویسند و پاک نمی‌کنند.
